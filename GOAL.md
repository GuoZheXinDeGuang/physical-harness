# GOAL — The North Star

> This document states the project's ultimate goal. It is fixed.
> Agents and contributors do not edit this file; changing the direction of the
> project is the operator's decision alone. Milestones, phases, and work logs
> live elsewhere — never here.

## The goal

**A foundation from which robots grow the ability to execute long-horizon tasks
in the real world — where every increment of ability is backed by experimental
evidence, never by demos or human judgment.**

Researchers plug new models, skills, and algorithms into the foundation as
plugins; the foundation itself never changes to accommodate any one of them.

## The two layers

**Layer 1 — the execution harness.** Take a large task → decompose it into a
chain of sub-tasks → match each to a skill → schedule by dependency → verify
world state after every step → replan on failure. The core owns orchestration
logic only. Reasoning models, navigation, mapping, perception, grasping, and
pretrained controllers are all pluggable. Simulators and real robots are two
embodiments behind one interface — both are modules. Real tasks run only
installed, frozen skills and sealed configuration; there is no online
trial-and-error.

**Layer 2 — recursive self-improvement (RSI).** Independent and offline, using
the execution harness as its laboratory instrument. Every candidate
improvement — whether a harness configuration change or a new skill — passes
one verification battery before installation:

1. paired comparison against its predecessor under identical conditions;
2. comparison against a judgment-free control (the blind twin);
3. one final evaluation on a held-out set that never touched development;
4. degradation measurement as sensing quality drops (the sim-to-real proxy).

What passes enters the skill library together with all of its evidence.
What fails is recorded honestly; a true null is a deliverable.

## Fixed principles — each one testable

- Boots with zero plugins, self-tests green.
- Interfaces validate at mount time; a bad provider fails at mount, not mid-task.
- Full configuration enters the content hash; a changed config is a different
  experiment identity.
- Runtime events form a chained, tamper-evident log that survives restarts.
- Every use of privileged information is recorded; every skill carries a
  measured privilege dependency.
- The two layers are one-directional: evolution calls execution to run
  experiments; execution consumes what evolution has sealed; execution never
  calls back.
