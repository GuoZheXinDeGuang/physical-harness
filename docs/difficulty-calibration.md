# 难度标定与「零特权可检测性」

实测，2026-08-19。robosuite Lift / Panda / 20Hz / horizon=100（5 秒）。

## 冻结策略的设计

策略在 t=0 **通过一个有噪声的传感器读一次方块位姿**，然后开环执行固定时长的四个阶段
（above 25 → descend 25 → close 12 → lift 38）。

这样设计的理由：这是真实 VLA 的典型失败形态 —— **基于一个错误的感知去执行**，而不是控制器算不动。
关键是它**可恢复**：重新读一次当前观测就能修正。对照实验里 kp=5 那种「根本够不着」的失败
是不可恢复的，对演化毫无价值，已排除。

## 难度曲线（N=40）

| 感知噪声 sd | 成功率 |
|---|---|
| 0.010 | 87.5% |
| 0.015 | 77.5% |
| **0.020** | **47.5%** |
| **0.025** | **37.5%** |
| 0.030 | 32.5% |

**选 sd=0.020~0.025，基线 37-48%。** 对照：Zetta 在 LIBERO-Pro 上的基线是 31-38%，同一量级。
既留足提升空间，信号又不稀疏。

## 核心发现：失败可被零特权信号检测

结束时的手指开度 `robot0_gripper_qpos` 差值：

| | finger_gap |
|---|---|
| 成功 | 0.038 ~ 0.046 |
| 失败 | **0.0010 ~ 0.0012** |

**40 倍分离。** 而 `robot0_gripper_qpos` 属于 `robot0_proprio-state` —— **真机上就有这个量**。

意义（这是整个项目论点的实证支撑）：

1. Zetta 会用 `privileged.task.manipulated_object.grasped` 写的那条 critic，
   在这里可以用**纯本体感受**写出来，不需要任何仿真器内部状态。
2. 所以「零特权 critic」不是理论上可能，是这个任务的**默认解**。
   我们的特权预算机制因此有了一个可演示的正例，而不只是一条规矩。
3. 恢复动作是明确且有界的：在 close 阶段末检测到「合拢但手里没东西」→ 张开 → 重读**当前**方块位姿 → 重新接近。
   这正好是 Zetta 的 critic-recovery 配对形态，但全程不碰特权信息。

失败时 `cube_z` 恒为 0.821（方块没被抬起，停在桌面），可作为特权侧的对照特征，
用来做消融实验：同一条 critic 分别用特权特征和本体感受特征写，比较两者的门禁结果。
